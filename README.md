# reinste.in

Personal blog at [reinste.in](https://reinste.in). Built with React + Vite, deployed on Vercel.

## Prerequisites

- Node.js 18+
- npm

## Setup

```bash
npm install
```

## Dev

```bash
npm run dev
```

Opens at `http://localhost:5173`.

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Deploy

The repo is connected to Vercel. Every push to `main` triggers a production deploy automatically.

To deploy manually:

```bash
npx vercel --prod
```
